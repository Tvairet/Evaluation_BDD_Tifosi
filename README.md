STRUCTURE DU PROJET : 

BD.sql : Script de création de la base de donnée avec utilisateur et droits d'accès.

donnees.sql : Script pour l'insertion des données dans les tables avec INSERT INTO.

requetes.sql : Script regroupant les requetes de test afin de vérifier la conformité de la base de données avec le projet demandé par le client.

tifosi.sql : Script pour la création des tables et les contraintes d'intégrité.

assets: Un dossier avec les feuilles Excels transmisent pour concevoir la base de données.
